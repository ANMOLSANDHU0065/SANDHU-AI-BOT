About SANDHU AI BOT

SANDHU AI BOT is a learning project built with Python, Flask, Natural Language Processing, and SQLite.

How it works

The NLP engine converts questions into TF-IDF vectors and compares them with sample questions using cosine similarity. Chat messages are stored in a local SQLite database.

This starter version uses an FAQ-based NLP engine. It is not a large generative language model yet.
